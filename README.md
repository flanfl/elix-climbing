# elix-climbing

A climbing app, built as a vehicle for learning Elixir / OTP / Phoenix (backend) and
React / TypeScript (frontend).

## Layout

| Path        | What                                              |
|-------------|---------------------------------------------------|
| `backend/`  | Phoenix JSON API (Elixir/OTP) — _not yet created_ |
| `frontend/` | Vite + React + TypeScript SPA — _not yet created_ |

## Prerequisites

- [mise](https://mise.jdx.dev) — installs the pinned toolchain from `mise.toml`
- Docker + Docker Compose — runs Postgres

## Getting started

```sh
mise install   # Erlang, Elixir, Node at the pinned versions
```
